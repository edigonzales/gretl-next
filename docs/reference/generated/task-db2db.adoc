|===
| [.acronym]#DSL#-Methode | Beschreibung | Erforderlich

| [.dsl-signature]#*batchSize*(int value)#
| Legt die [.acronym]#JDBC#-Batch-Grösse für Zieleinfügungen fest.
| [.optional]#nein#

| [.dsl-signature]#*fetchSize*(int value)#
| Legt die [.acronym]#JDBC#-Fetch-Grösse für Quell-Lesevorgänge fest.
| [.optional]#nein#

| [.dsl-signature]#*sourceDatabase*(String jdbcUrl)#
| Konfiguriert die Quell-Datenbankverbindung mit einer [.acronym]#JDBC#-URL.
| [.required]#ja#

| [.dsl-signature]#*sourceDatabase*(String jdbcUrl, String username, String password)#
| Konfiguriert die Quell-Datenbankverbindung mit [.acronym]#JDBC#-URL, Benutzername und Passwort.
| [.required]#ja#

| [.dsl-signature]#*sqlParameterSets*(Map<String, ?>\... parameterSets)#
| Gibt mehrere [.acronym]#SQL#-Parameter-Maps an. Für jede Map werden alle Transfers in Reihenfolge ausgeführt.
| [.optional]#nein#

| [.dsl-signature]#*sqlParameters*(Map<String, ?> parameters)#
| Legt eine [.acronym]#SQL#-Parameter-Map für eine einzelne Ausführung aller Transfers fest.
| [.optional]#nein#

| [.dsl-signature]#*targetDatabase*(String jdbcUrl)#
| Konfiguriert die Ziel-Datenbankverbindung mit einer [.acronym]#JDBC#-URL.
| [.required]#ja#

| [.dsl-signature]#*targetDatabase*(String jdbcUrl, String username, String password)#
| Konfiguriert die Ziel-Datenbankverbindung mit [.acronym]#JDBC#-URL, Benutzername und Passwort.
| [.required]#ja#

| [.dsl-signature]#*transfer*(Action<TransferConfig> action)#
| Gibt einen Transfer mit verschachtelter Konfiguration an: [.dsl-method]#`sqlFile(\...)`#, [.dsl-method]#`targetTable(\...)`#, [.dsl-method]#`deleteAllRows(\...)`# und [.dsl-method]#`geometryColumns(\...)`#.
| [.required]#ja#

| [.dsl-signature]#*transfer*(Object sqlFile, String targetTable, boolean deleteAllRows, String\... geometryColumns)#
| Gibt einen Transfer aus einer [.acronym]#SQL#-Datei in eine Zieltabelle an.
| [.required]#ja#
