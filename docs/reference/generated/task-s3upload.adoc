[cols="4,1,5,1", options="header"]
|===
| DSL-Methode | Standard | Beschreibung | Erforderlich

| `accessKey(String accessKey)`
|
| Konfiguriert den S3-Zugriffsschlüssel.
| ja

| `acl(String acl)`
|
| Konfiguriert die S3-Canned-ACL.
| ja

| `bucketName(String bucketName)`
|
| Konfiguriert den S3-Bucket-Namen.
| ja

| `contentType(String contentType)`
|
| Konfiguriert den Content-Type der hochgeladenen Objekte.
| nein

| `endpoint(String endpoint)`
|
| Konfiguriert den S3-Endpunkt.
| nein

| `metadata(Map<String, String> metadata)`
|
| Konfiguriert S3-Objekt-Metadaten.
| nein

| `region(String region)`
|
| Konfiguriert die S3-Region.
| nein

| `secretKey(String secretKey)`
|
| Konfiguriert den geheimen S3-Schlüssel.
| ja

| `sourceDir(Object sourceDir)`
|
| Legt ein Verzeichnis fest, dessen direkte Dateien hochgeladen werden.
| nein

| `sourceFile(Object sourceFile)`
|
| Legt eine hochzuladende Datei fest.
| nein

| `sourceFiles(Object sourceFiles)`
|
| Legt eine Dateisammlung zum Hochladen fest.
| nein

|===
