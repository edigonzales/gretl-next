[cols="4,1,5,1", options="header"]
|===
| DSL-Methode | Standard | Beschreibung | Erforderlich

| `database(Object file)`
|
| Konfiguriert die DuckDB-Datenbankdatei.
| ja

| `exports(Action<ExportsConfig> action)`
|
| Konfiguriert Exporte, die nach den SQL-Dateien ausgeführt werden.
| nein

| `inMemoryDatabase()`
|
| Verwendet eine In-Memory-DuckDB-Datenbank anstelle einer Datenbankdatei.
| nein

| `installExtensions(boolean value)`
|
| Installiert erforderliche DuckDB-Erweiterungen vor dem Laden. Für die lokale Entwicklung vorgesehen.
| nein

| `sources(Action<SourcesConfig> action)`
|
| Konfiguriert föderierte Quellen.
| ja

| `sqlFiles(Object... paths)`
|
| Gibt SQL-Dateien an. Pfade werden relativ zum Gradle-Projekt aufgelöst.
| ja

| `sqlParameterSets(Map<String, ?>... parameterSets)`
|
| Gibt mehrere SQL-Parameter-Maps an. Für jede Map werden alle SQL-Dateien in Reihenfolge ausgeführt.
| nein

| `sqlParameters(Map<String, ?> parameters)`
|
| Legt eine SQL-Parameter-Map für eine einzelne Ausführung aller SQL-Dateien fest.
| nein

| `targets(Action<TargetsConfig> action)`
|
| Konfiguriert beschreibbare Ziele für SQL und Exporte.
| nein

|===
